# 247 Media DJ – Hannes Hergenröther

Persönliche Website für **247 Media DJ** – Videoproduktion, DJ-Sets und Content Creation von Hannes Hergenröther.

## Seiten

| Datei | Inhalt |
|---|---|
| `index.html` | Hauptseite mit Hero, Leistungen, YouTube-Video, Kontakt und Footer |
| `impressum.html` | Impressum (gesetzlich vorgeschrieben) |
| `datenschutz.html` | Datenschutzerklärung inkl. YouTube-Consent |

## Features

- **Kein Framework, kein Build-Step** – reines HTML/CSS/JS
- **Responsive** – Mobile-First, Hamburger-Nav unter 768 px
- **YouTube Privacy-Consent** – Video wird erst nach Nutzerbestätigung geladen (`youtube-nocookie.com`)
- **Scroll-Reveal** – Elemente mit `IntersectionObserver` eingeblendet
- **Stat-Counter** – Zahlen werden beim Einblenden animiert hochgezählt
- **Design System** – Cal.com-inspirierte Tokens (Farben, Abstände, Typografie) in CSS-Variablen, dokumentiert in `DESIGN.md`

## Lokal öffnen

```bash
open index.html
```

Oder einen lokalen Server starten (verhindert mögliche CORS-Einschränkungen):

```bash
npx serve .
```
